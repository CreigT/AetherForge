# AetherForge Collective

Workspace intelligence, made physical.

AetherForge is an interactive concept application for customized modular workspace systems designed by collaborating AI agents and produced through regional fabrication partners.

## Experience

- Responsive editorial landing page
- Interactive Focus, Create, and Restore workspace modes
- Modular system configurator with live concept pricing
- Customer brief prototype
- Agent-driven design-to-delivery narrative
- Technical architecture and operating model

## Run locally

Requirements: Node.js 22.13 or newer and pnpm.

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Build

```bash
pnpm build
```

The application uses Vinext and produces a Cloudflare Worker-compatible Sites build.
